COLLABORATIVE SPREADSHEET

Colwork.

基于 Yjs 的多人协作表格，以原生 DOM 渲染，轻松接入 Vue 与 React。

实时协作固定行列单元格保护快照与更新日志
仓库 github.com/dlwm/colwork ↗

从一个简单示例开始

在仓库中运行 npm run build:lib，将 dist/colwork.js 和 dist/colwork.css 放入应用的 src/vendor/colwork/，即可按下面的方式引入。

本地协作服务使用 ws://127.0.0.1:1234；部署后将连接地址改为自己的 wss://域名/rooms。持久化后端可添加 initializeAfterSync: true，先同步保存的数据再初始化表格。

V

Vue 3

使用 Composition API 管理表格实例。

打开 Vue 示例 →
引入与基础配置App.vue
<script setup>
import { ref, onMounted, onBeforeUnmount } from 'vue'
import { ColworkTable } from './vendor/colwork/colwork.js'
import './vendor/colwork/colwork.css'

const root = ref(null)
let table

onMounted(() => {
  table = new ColworkTable(root.value, {
    room: 'colwork-demo',
    user: 'Vue 协作者',
    userColor: '#42b883',
    transport: 'websocket',
    websocketUrl: 'ws://127.0.0.1:1234',
    rowCount: 100,
    columnCount: 10,
  })
})

onBeforeUnmount(() => table?.destroy())
</script>

<template>
  <div ref="root" />
</template>
R

React

使用 Hooks 创建实例并在卸载时清理。

打开 React 示例 →
引入与基础配置App.jsx
import { useEffect, useRef } from 'react'
import { ColworkTable } from './vendor/colwork/colwork.js'
import './vendor/colwork/colwork.css'

export default function App() {
  const root = useRef(null)

  useEffect(() => {
    const table = new ColworkTable(root.current, {
      room: 'colwork-demo',
      user: 'React 协作者',
      userColor: '#0891b2',
      transport: 'websocket',
      websocketUrl: 'ws://127.0.0.1:1234',
      rowCount: 100,
      columnCount: 10,
    })

    return () => table.destroy()
  }, [])

  return <div ref={root} />
}
